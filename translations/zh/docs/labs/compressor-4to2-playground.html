🗜️ 4:2近似压缩器实验台

精确4:2压缩器（4:2 compressor）接收同一列的四个比特（X₁–X₄），加上相邻压缩器送来的输入进位，输出和位Sum（位权1）及两个位权2的输出Carry、Cout，使X₁+X₂+X₃+X₄+Cin = Sum + 2·(Carry + Cout)。单击输入比特，与Momeni等人的两种近似设计比较（IEEE Trans. Computers，2015）。

引导任务：各控件的作用（静态说明）

开始之前： 全加器（Full Adder，FA）将同一列的三个比特计数为和位 + 2·进位（见“近似乘法器”页入门部分第3步）。4:2压缩器对四个比特加输入进位计数。小例子：四个1且输入进位 = 0时，4 = 0 + 2·1 + 2·1，即和位 = 0、进位 = 1、输出进位Cout = 1。

控件与读数

  • 顶部菜单：设计1保留输入进位与Cout；设计2没有这两项，因此只与X₁ + X₂ + X₃ + X₄比较。
  • X₁–X₄与输入进位圆圈：单击圆圈，在0与1之间切换该比特。设计2忽略输入进位圆圈。
  • 精确4:2压缩器 卡片：精确输出及对应数值，括号内为应得计数。 近似设计 卡片：所选设计的相同信息。
  • 当前输入：显示“正确”，或“错误”及有符号差值（近似结果 − 应得值）。 错误行数：全部输入行中，精确压缩器及所选设计分别算错多少行。
  • 完整真值表 （底部）：各输入行及其输出，当前输入高亮显示。如果无法单击圆圈，可在此读取每种情况。

任务1。 实验默认X₂ = 1、X₄ = 1。预测计数及设计1是否正确，再读取卡片。

任务2。 设置X₁ = X₂ = X₃ = X₄ = 1、输入进位 = 0。先预测，再读取两张卡片与 当前输入.

任务3。 将输入进位切换为1，再选择设计2。为什么设计2卡片的应得值仍为4？
