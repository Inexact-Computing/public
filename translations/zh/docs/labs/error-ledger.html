多久出错一次，误差又有多大？

本表比较你提供的整数结果，不模拟电路。每格接受−1,000,000至1,000,000的整数，单位与结果相同。误差距离（Error Distance，ED）是误差的绝对值；相对误差距离（Relative Error Distance，RED）是误差距离相对于非零精确参考值绝对值的比值。错误率（Error Rate，ER）是结果出错的观测所占比例；平均误差距离（Mean Error Distance，MED）对全部观测的误差距离取平均，包含零误差观测；平均相对误差距离（Mean Relative Error Distance，MRED）仅对已定义的相对误差距离取平均，排除零参考值观测。

1. 预测（选填）

不收集或保存分数。准备好观察结果时，点击检查。

2. 输入成对结果

使用ASCII十进制整数，如-10、01或0。允许两端空格，不接受+1、小数或指数写法。两格均空时不计入统计；仅一格空或任意格无效时，整个汇总不可用。

选做：检查前预测每行的e和ED

以结果单位输入有符号误差e和非负误差距离ED。任一预测留空即可跳过。预测不会改变提供的结果，也不会计分或保存。

4. 思考

ED衡量每次误差的大小，符号相反也不能抵消ED。错误率ER统计出错行，平均误差距离MED对误差大小取平均。零参考值行计入MED、ER，但RED未定义，因此从平均相对误差距离MRED中排除。

观测最大误差只描述本表，不是覆盖电路全部输入的保证。后续计算仍使用精确比值，不以舍入后的百分比代替。

边界情况核对

抵消：精确值[10,10]，近似值[9,11]，得到e = [-1,1]、ED = [1,1]，有符号平均误差 = 0，但MED = 1个结果单位；ER = 100%，最大值 = 1个单位；MRED = 10%（Nvalid为2，排除0个观测）。

零参考值：精确值[0,0]，近似值[0,1]，得到N = 2，出错 = 1，MED = 1/2个结果单位，ER = 50%，最大值 = 1个单位；MRED未定义（Nvalid为0，排除2个观测）。若两个近似值均为0，MED、ER及最大值都为零，但MRED仍未定义。

负参考值：[-10,-20]与[-9,-22]比较，得到e = [1,-2]、ED = [1,2]、MED = 3/2个单位、ER = 100%、最大值 = 2个单位；MRED = 10%（Nvalid为2，排除0个观测）。使用参考值绝对值，使RED保持非负。

全部正确：[0,8]与[0,8]比较，得到N = 2，出错 = 0，MED = 0个单位，ER = 0%，最大值 = 0个单位；MRED = 0%（Nvalid为1，排除1个观测）。空表N = 0、出错 = 0、Nvalid = 0、排除0个观测；MED、ER、最大值及MRED均未定义。
