🗜️ 4:2 Approximate Compressor Playground

An exact 4:2 compressor takes four bits of the same column (X₁–X₄) plus a carry-in from the neighbouring compressor and produces Sum (weight 1) and two outputs of weight 2, Carry and Cout, so that X₁+X₂+X₃+X₄+Cin = Sum + 2·(Carry + Cout). Click the input bits to compare it with the two approximate designs of Momeni et al. (IEEE Trans. Computers, 2015).

Guided tasks: what each control does (static text)

Before you start: a full adder counts three bits of one column as Sum + 2·Carry (Step 3 of the “Start here” part of the Approximate Multipliers page). A 4:2 compressor counts four bits plus Carry In. Small example: four 1s and Carry In = 0 make 4 = 0 + 2·1 + 2·1, that is Sum = 0, Carry = 1, Cout = 1.

Controls and readings

  • Menu at the top: Design 1 keeps Carry In and Cout; Design 2 has neither, so it is compared with X₁ + X₂ + X₃ + X₄ only.
  • Circles X₁–X₄ and Carry In: click a circle to switch that bit between 0 and 1. In Design 2 the Carry In circle is ignored.
  • Exact 4:2 Compressor card: the exact outputs and their value, with the expected count in brackets. Approximate Design card: the same for the chosen design.
  • This input: Correct, or Wrong with the signed difference (approximate − expected). Wrong rows: how many of all input rows the exact compressor and the chosen design get wrong.
  • Full truth table (bottom): every input row with its outputs; the current input is highlighted. If you cannot click the circles, you can read every case there.

Task 1. The lab opens with X₂ = 1 and X₄ = 1. Predict the count and whether Design 1 is correct, then read the cards.

Task 2. Set X₁ = X₂ = X₃ = X₄ = 1 with Carry In = 0. Predict, then read both cards and This input.

Task 3. Switch Carry In to 1, then choose Design 2. Why does the expected value in the Design 2 card stay at 4?
