Error Ledger

How often are results wrong, and by how much?

This ledger compares supplied integer results. It does not simulate a circuit. Each cell accepts −1,000,000 to 1,000,000 integer result units.

1. Predict (optional)

No score is collected or stored. Check when you are ready to observe the results.

2. Enter paired results

Use ASCII decimal integers, such as -10, 01 or 0. Outer spaces are allowed; +1, decimals and exponent notation are not. Both cells blank: ignored in statistics. One blank or any invalid cell: the entire summary is unavailable.

Optional: predict e and ED for each row before checking

Enter signed e and nonnegative ED in result units. Leave either prediction blank to skip it. These predictions do not change the supplied results and are not scored or stored.

Each exact and approximate value, e and ED is in integer result units. RED is a nonnegative ratio.

3. Observe and explain

No current result. Check this table to reveal its row calculations and summary.

4. Reflect

ED measures the size of each mistake; opposite signs cannot cancel ED. ER counts wrong rows, while MED averages their sizes. The zero-reference row counts in MED and ER, but its RED is undefined and excluded from MRED.

The observed maximum describes only this table. It is not a circuit-wide guarantee. Rounded percentages never replace exact ratios in later calculations.

Boundary checks

Cancellation: exact [10,10], approximate [9,11] gives e = [-1,1], ED = [1,1], signed mean error = 0 but MED = 1 result unit; ER = 100%, maximum = 1 unit; MRED = 10% (Nvalid 2, excluded 0 observations).

Zero references: exact [0,0], approximate [0,1] gives N = 2, wrong = 1, MED = 1/2 result unit, ER = 50%, maximum = 1 unit; MRED is undefined (Nvalid 0, excluded 2 observations). With both approximate values 0, MED, ER and maximum are zero; MRED remains undefined.

Negative references: [-10,-20] versus [-9,-22] gives e = [1,-2], ED = [1,2], MED = 3/2 units, ER = 100%, maximum = 2 units; MRED = 10% (Nvalid 2, excluded 0 observations). Absolute reference magnitudes keep RED nonnegative.

All correct: [0,8] versus [0,8] gives N = 2, wrong = 0, MED = 0 units, ER = 0%, maximum = 0 units; MRED = 0% (Nvalid 1, excluded 1 observation). Empty tables have N = 0, wrong = 0, Nvalid = 0, excluded = 0 observations; MED, ER, maximum and MRED are undefined.

For 32 versus 33, RED = 1/32 = 3.125%, displayed as 3.13% by round-half-up to two decimal places. A display is rounded; its ratio remains exact.
