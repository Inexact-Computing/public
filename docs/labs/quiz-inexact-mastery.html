📘 How to use this quiz (read this first)

This is an optional advanced self-check. Its four questions cover three earlier topics: bit weights (Bits and carries), the error metrics ED / MED / ER (Error metrics made easy), and what a ripple-carry adder's delay depends on (Approximate adders).

  • It is fine to score 4/4 here without having read any new page on this site: it tests those prerequisites, not the newer material.
  • It does not replace the "Check your understanding" questions inside the pages themselves (the WB-numbered questions). Those check the page they sit on; this quiz checks the ground underneath them.
  • Each question locks once you answer. It marks the right option, marks yours if it differs, and explains the reasoning. The 🔄 Retake Quiz button clears every answer and starts again.
  • Nothing is scored, saved or sent anywhere — the counter is local to this page and resets when you reload it.

To get real value out of it, work on paper first: pick an option, then write one sentence saying why each of the other three is wrong.

1. An exact 4-bit adder gives 7 + 1 = 8, but an approximate adder returns 7. The sum is only used to decide "is it at least 8?". What happens to that decision?
2. In an unsigned binary number, bit 2 (counting from bit 0 on the right) changes from 0 to 1. Nothing else changes. How does the value change?
3. In an exact ripple-carry adder, what usually sets the longest delay (the critical path)?
4. Assume the result has enough bits. Multiplying 3 (binary 0011) by 23 can be done by shifting it left 3 places. What is the result?
