🧭 CORDIC Coordinate Rotation Visualizer Lab

Rotation-mode CORDIC turns the unit vector (1, 0) towards θ using micro-rotations by atan(2−i), each needing only shifts and additions in hardware. This page emulates the recurrence in floating point (no fixed-point word length is modelled); the angle and magnitude shown are measured from the resulting vector.

Guided tasks: what each control does (static text)

Before you start: the “Start here” part of the Approximate CORDIC page: coordinates, turning an arrow by small angles whose tangent is 1, ½, ¼, …, and scaling. Small example: from (1, 0), step 0 turns +45° to (1, 1); step 1 turns −26.57° to (1 + 1 × 0.5, 1 − 1 × 0.5) = (1.5, 0.5). Both new values use the old x and y.

Controls and readings

  • Target Angle (θ): −90° to 90° in steps of 0.5°. Number of CORDIC Iterations: 1 to 8. Drag a slider, or click it and use the arrow keys.
  • Approximation Mode: Fixed count runs all N steps and scales by KN; Early termination stops after step 3 or later once the leftover angle is below 1°; Approximate scale factor 0.625 runs all N steps but scales by 0.625.
  • Vector Angle and Magnitude: measured from the final arrow. Angle Error = vector angle − θ. Magnitude should be 1 after correct scaling.
  • Iterations Run: steps actually executed, out of N. Scale Used: the factor applied at the end. Residual z: the leftover angle.
  • Picture: the circle has length 1, the dashed line is the target, the teal arrow is the scaled CORDIC result drawn at its computed length.

Task 1. Predict the vector angle for θ = 30° with 5 fixed steps. Set Target Angle 30.0°, 5 iterations and Fixed count, then read.

Task 2. Change to 8 iterations. What happens to the angle error and the scale?

Task 3. Back at 5 iterations, choose Approximate scale factor 0.625. Which reading changes, and which stays the same?
