Bit weights

Each position has its own weight: 8, 4, 2, 1. This is an unsigned value from 0 to 15.

The leftmost bit is worth 8 here. Add the weights whose bits are 1.

Gates and a local full adder

A gate returns one bit. A full adder preserves the total using a sum bit and a carry bit. The local carry-in here never enters the whole-word addition view.

Make a prediction, or skip it, then check.

Carry by column

Enter two decimal integers from 0 to 15. Initial carry C0 = 0 is fixed. Start at the rightmost bit (bit 0), then move left one column at a time.

Use decimal digits only, with optional outer spaces or a minus sign. Leading zeros and −0 are allowed; values must still be 0–15. Plus signs, decimals, exponents and hexadecimal are rejected.
