# Interactive Inexact Computing Labs

Welcome to the interactive hands-on laboratory! Here you can experiment directly in your web browser with real approximate arithmetic algorithms, image filters, and circuit simulators.

---

## 🧪 Choose Your Interactive Lab

| Lab | Description | What You'll Learn |
| :--- | :--- | :--- |
| 🎛️ [**Multiplier Playground**](multiplier-explorer.html) | Live interactive multiplier comparison. Enter any two numbers or drag sliders to see exact vs. approximate outputs, error distance, and transistor savings. | How DRUM, RoBA, and Truncation trade accuracy for silicon area. |
